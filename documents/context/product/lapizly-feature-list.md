# Lapizly — SMM Automation Agent
### Feature List (MVP → Future)

---

## 🟢 Phase 1 — MVP Core (Automate First)

| Feature | Description |
|---|---|
| Content Calendar Generator | AI generates monthly post ideas based on niche, brand voice, content pillars |
| AI Caption Writer | Generates captions, hooks, and CTAs per platform tone |
| Hashtag/Keyword Suggestions | Auto-suggests relevant hashtags & alt text/SEO keywords |
| Auto-Scheduling & Publishing | Schedules & posts via platform APIs (Meta, X, LinkedIn, etc.) |
| Cross-Platform Reformatting | Adapts same content for IG/LinkedIn/X tone & length differences |
| Basic Analytics Dashboard | Pulls engagement, reach, follower growth into one view |

**Core Loop:** Calendar → Caption → Auto-Post → Analytics feedback

---

## 🟡 Phase 2 — Medium Complexity (Needs Guardrails)

| Feature | Description |
|---|---|
| AI Visual Generation | Auto-generates graphics/images from templates |
| Trend Detection | Surfaces trending hashtags/audio (human approves before posting) |
| Performance-Based Suggestions | "Posts like X performed well — generate similar" |
| Templated Auto-Replies | FAQ-type auto-responses to comments/DMs |
| A/B Testing Engine | Tests captions/post times automatically, picks winner |

---

## 🔴 Phase 3 — Human-in-Loop / Later

| Feature | Description |
|---|---|
| Full Community Management | Context-sensitive replies, tone judgment |
| Crisis/PR Management | Handling negative sentiment, brand risk |
| Influencer Outreach | Negotiation & relationship building |
| Paid Ad Optimization | Budget + targeting decisions |
| Brand Judgment Calls | Anything requiring nuanced brand decisions |

---

## Notes
- MVP wedge = tight loop that avoids risky human-judgment areas
- Phase 2/3 features bolt on once trust + data is established
